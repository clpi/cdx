# cdx

Written mainly in C++, C, Shell, Makefile.

## Contents

- `.ccls-cache` — directory
- `Makefile` — the build file
- `build.ninja` — a file
- `dist` — directory
- `src` — source code
- `x.py` — a Python file
- `x.sh` — a shell script

## Build and run

Build targets defined in the `Makefile`: `CC`, `CFLAGS`, `OUTD`, `BIND`, `OBJD`, `LIBD`, `SRCD`, `BIN`, `SRC`, `SRCF`, `OUTB`, `OUTO`.
